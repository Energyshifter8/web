Дүгнэлт

Хоёр хувилбар ижил хуудас гаргасан ч арга нь өөр. Bootstrap нь navbar, card, form validation, collapse зэрэг бэлэн компоненттой тул хурдан эхэлж, HTML-д цөөн class (нэг card-д 13) бичдэг боловч ашиглаагүй хэсгийг нь ч гэсэн бүх framework-ийг (CSS + JS ≈ 309 KB, gzip ≈ 54 KB) CDN-ээс татдаг. Tailwind нь build хийх алхам шаардаж, нэг card-д илүү олон utility class (20) бичдэг тул HTML урт болдог ч зөвхөн ашигласан class-аа CSS-д гаргадаг тул CSS + JS нь ≈ 22 KB (gzip ≈ 5.5 KB) буюу ойролцоогоор 10 дахин бага. Lighthouse-ын accessibility, best practices, SEO оноо хоёуланд нь 100 гарсан бөгөөд performance-ийн ялгаа бага (mobile 71 ба 76, desktop 100 ба 99) байсан нь хоёр хуудасны ачааллыг ихэвчлэн зураг, видео, газрын зураг тодорхойлж байгааг харуулж байна. Иймд бэлэн компонентоор хурдан прототип хийхэд Bootstrap, өөрийн загвартай, хөнгөн хуудас хийхэд Tailwind илүү тохиромжтой гэж дүгнэлээ.
